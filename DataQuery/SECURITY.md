# 安全说明

## 当前边界

本项目是本地/内部 Demo。默认 `/api/query` 没有用户认证、限流、租户隔离或细粒度数据权限；请勿直接将默认 Compose 服务暴露到公网。

## 发布前必须处理

- 历史配置中曾出现 LLM API Key 和数据库密码。发布前请先在对应平台撤销/轮换，再清理工作区和 Git 历史。
- 不要提交 `.env`、连接串、私钥、日志、签名下载链接、数据库导出元信息或未经确认的业务数据。
- 如果秘密已经进入远程 Git 历史，仅删除当前文件无效；请使用经过审核的历史清理流程，并通知已有 clone 的使用者。

## SQL 安全

后端仅用于查询，Repository 会拒绝多语句和写操作，并校验动态标识符。生产部署仍应额外使用：

- 最小权限的只读 DW 数据库账号。
- 表名/字段名白名单或 AST 级 SQL 审查。
- 查询超时、最大返回行数和资源配额。
- 不回显连接串、完整异常、提示词或敏感结果。

## 基础设施

Compose 中的 Elasticsearch 无认证、Qdrant 无认证且服务端口映射到宿主机，这些设置只适合本地开发。生产环境应使用私有网络、认证、TLS、Secret 管理和访问控制。

## 报告漏洞

请不要在公开 Issue 中发布凭据、个人数据或可直接利用的漏洞。请先通过仓库维护者约定的私密渠道报告，并提供复现条件、影响范围和建议修复方案。
